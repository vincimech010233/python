# Python Technical Exercises

[Español](README.es.md)

A collection of Python exercises and notebooks covering algorithms, scientific computing, data processing, cryptography practice, and engineering calculations.

## Highlights

- Numerical work: pendulum error analysis, Newton–Raphson, free fall, hydrostatic pressure, and production-line notebooks.
- Algorithms: Sudoku, trees, matrices, paths, number theory, parsing, and encoding exercises.
- Security learning: Cryptopals and picoCTF notebooks.
- Data and visualisation experiments.

Most files are independent exercises:

```bash
python3 path/to/script.py
```

Notebook dependencies vary and should be installed in an isolated virtual environment.

## Status and limitations

This repository is a learning archive, not a single package. There is no shared dependency file or unified test suite yet. Individual projects should be extracted and tested before production use.

## Security

Examples use local or challenge data. Never insert live credentials or confidential datasets.
