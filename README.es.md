# Ejercicios técnicos en Python

[English](README.md)

Colección de ejercicios y notebooks sobre algoritmos, cálculo científico, tratamiento de datos, prácticas de criptografía y cálculos de ingeniería.

Incluye análisis numérico, problemas algorítmicos, notebooks de Cryptopals y picoCTF, y experimentos de visualización. La mayoría de archivos son independientes y pueden ejecutarse con Python 3.

## Estado

Es un archivo de aprendizaje, no un paquete único. Todavía no dispone de dependencias compartidas ni una suite global de pruebas. Cada proyecto deberá aislarse y probarse antes de utilizarlo en producción.
